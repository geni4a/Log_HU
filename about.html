How the calculator works

Initial Dosing. The daily dose is the patient's weight multiplied by the chosen starting dose (15, 20, or 25 mg/kg/day), capped at 2000 mg/day. The tool then converts this to the selected formulation:

  • Capsules: if the daily dose divides evenly into whole capsules, the same number is given every day. Otherwise the dose is rounded down to whole capsules per week and spread as evenly as possible across the days. The result also shows the weight at which the next capsule per week would be added, with its schedule.
  • Siklos: dosed in 250 mg blocks of the scored tablet, with the same weekly spread and escalation weight.
  • Liquid: the daily dose in mg is converted to mL using the concentration.

If baseline labs are entered, they are checked first. If they meet the toxicity criteria below, no starting dose is calculated and the labs should be reviewed. If the absolute reticulocyte count is left at 0, it is calculated from the RBC count and reticulocyte percentage.

Dose Optimization. This calculator evaluates current lab values only, using the criteria below, and returns one recommendation.

ARC = absolute reticulocyte count; Hb = hemoglobin. Within a column, all the neutrophil, platelet, and reticulocyte/hemoglobin criteria must be met, except for toxicity, where meeting any one criterion counts. If more than one column applies, the calculator reports them in this order: escalation, then weight-gain adjustment, then toxicity; otherwise it reports that the dose is optimized.

The calculator evaluates lab values only. It does not check how far the dose has moved from the starting dose, or whether toxicity has persisted beyond 2 weeks; these need to be confirmed by the clinician.

Clinical decision support tool only. Always confirm recommendations with a qualified clinician.
